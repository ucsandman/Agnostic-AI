# Decisions

- 2026-09-16 — **One adapter, many consumers.** All product-facing Mods consume `adapter/claude-runtime`'s `runtime.emit` bus and `$.runtime.*`; only the adapter reads Anthropic's raw function-hook events. Reason: the API is early access (`claude-code.d.ts` header), undocumented publicly, and already had one breaking change (`hooks.json.surface` removed). [stated in brief, shape chosen here]
- 2026-09-16 — **Never build on `classic.*`, `prompt.section/context`, `skill.prompt`, `attribution.text` from the user tier.** `sec-default@builtin` withholds them wherever managed settings exist (this machine: `C:\Program Files\ClaudeCode\managed-settings.json`). Products branch on the adapter's probed `supports` flags instead. [observed]
- 2026-09-16 — **Rewrite over deny for routing.** `agent.spawn` model rewrites are CONFIRMED and do not trigger the retry pathology the classic `fable-delegate-guard` logged (714 overrides, denies retried 5–7×). Deny only when no rewrite fixes it. [observed]
- 2026-09-16 — **Every rewrite explains itself to the model** via `context[]` on the result. Silent rewrites (model, containment) left the model reasoning from a false belief in `DOGFOOD.md`. [observed]
- 2026-09-16 — **Semantic judgment is behind a generic `judge()` with three backends** (stub, in-process `$.model.complete`, TypeSafe Jev). Deterministic policy stays authoritative; judgments are signals. Jev is one implementation, not a dependency. [stated in brief]
- 2026-09-16 — **Prototypes are `--plugin-dir` only, never installed.** Production harness, DashClaw, offlocal, Leg untouched; migration is per-guard behind a mode flag with a Mods leg added to `guard-canary` first. [stated in brief]
- 2026-09-16 — **Repository is private.** `snapshot/2.1.273/claude-code.d.ts` is extracted from Anthropic's binary and the evidence logs carry local paths; keep private until Anthropic documents the API and the logs are scrubbed. [inferred]
- 2026-09-16 (Phase 2) — **Promote with a per-session stand-down, never dual enforcement.** A classic guard yields a decision only when `mods-config.json` says `mod` AND the Mod's heartbeat for that session armed the guard (`hooks/lib/mods-mode.cjs` ≡ `harness-mods/hooks/lib/modes.mjs`). Shadow mode proved the alternative fails: classic denies fire before `agent.spawn` exists (6 of 14 routing keys classic-only). [observed]
- 2026-09-16 (Phase 2) — **All five guards MOD DEFAULT the same day** (routing, contextNudge, secretRedaction, subagentAccounting, readCache) on measured evidence (Run B 6/6 intended, redaction 0 raw values in transcript, canary 8/8), with classic code retained and rollback by config/env. Reason: Wes's controlled-aggression brief; the experimental-API risk is carried by the adapter, capability probes, the canary and the stand-down. [stated + observed]
- 2026-09-16 (Phase 2) — **Installed plugins over `--plugin-dir`.** A local `directory` marketplace (`~/.claude/mods`) loads live from the source folder in marketplace order; rollback is `claude plugin disable`. [observed]
- 2026-09-16 (Phase 2) — **A replaced tool result is a fresh object.** Spreading the original leaked the raw value to outer plugins through `text`. [observed]
- 2026-09-16 (Phase 2) — **Cross-repo integrations are interfaces, not wiring, where another session owns the file** (leg `attach.mjs`, handoff `cli.py`); the one-line wiring is documented in each repo. [stated: file ownership rule]

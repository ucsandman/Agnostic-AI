# The 2026-09 consolidation

On 2026-09-19 the harness went from five repositories partially owning one system to two: this public repository (the operating system) and a private overlay (the user profile). This note is the record; [PROVENANCE.md](PROVENANCE.md) lists every moved file with its source commit, [ownership.md](ownership.md) is the resulting matrix.

## Before

| Repository | What it held | Fate |
|---|---|---|
| `claude-config` (`~/.claude`, private) | hooks, tools, Mods, agents, workflows, jobs, docs, rules profile, memory, settings | stays private; now the overlay only (`overlay/`, memory, meditations, commands, settings, generated `CLAUDE.md`) |
| `agnostic-ai` (public) | the port engine, the rules compiler, two engine guards, the context graph | the canonical repository: everything portable moved in |
| `claude-harness` (public mirror) | a curated copy of `~/.claude`, refreshed by a sync script 36 times | retired; its snapshot is `examples/installed-harness`; ready to archive |
| `claude-mods-rnd` (private) | the Mods research record, prototypes, lab, experiments | code and record moved to `labs/claude-mods`; the two production Mods to `engine/mods`; experiment data stays private there; ready to archive |
| `markdown-agent-memory` (public) | memory policy, templates, install prompt, the linter | `packages/markdown-agent-memory` and `tools/memory-lint`; ready to archive |
| `claude-commands` (public) | slash commands, as a submodule of `~/.claude` | absorbed into the overlay as plain files; ready to archive |

Kept as separate products (they are not harness code): the skills library, `context-handoff-bundle`, DashClaw, declick, LegCli, `agent-comms` (private data), `agent-capsule`.

## What changed on the machine

- `~/.claude/{hooks,tools,mods,agents,workflows}` are links (junctions on Windows) into this checkout, bound by `engine/setup/link.cjs`. The originals were moved to `~/.claude/.agnostic-migrated/<name>-<stamp>/`, not deleted.
- `~/.claude/CLAUDE.md` is generated by `engine/sync/claude-md.cjs` from the rules import and `overlay/profile.md`; the previous symlink to an external `AGENTS.md` writer is gone.
- Eight Task Scheduler jobs were re-pointed to `jobs/` and `tools/` here by `node jobs/install.cjs --apply`.
- `npm run doctor` is the drift and boundary check; `npm run sync` binds links and assembles `CLAUDE.md` as well as compiling rules.

## What the migration surfaced and fixed

- A relative root in a context-graph config read through a link resolved against the link's parent, so the rules and docs roots loaded zero modules; the loader now resolves against the config file's real directory.
- The Mods sandbox has no Node globals: an environment read at module load kept both Mods from loading for one session. They read the home through `$.env` on their first event now.
- Thirty-two transcript-derived data files came along with the research record and were public for a day. They are untracked and ignored; the doctor's `data-files` check fails on any recurrence. Their history is a decision recorded in the final report.
- Twenty-four public files carried the author's home path; they now use `~`, a placeholder or a value derived from the Claude home, and the doctor fails on the author's account name in public code.
- `sync` and `port` both wrote the non-Claude rules files; `sync` is now primary-client-only and `port` is the single writer of the rest.

## Deleting the safety copies

After a week of green doctors: `~/.claude/.agnostic-migrated/` (25 MB) can go. The four source repositories carry an archive pointer at the top of their README; archiving them on GitHub is the owner's call.
